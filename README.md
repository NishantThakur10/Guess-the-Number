# Guess-the-Number
Description

This is a simple Guess the Number game built using HTML, CSS, and JavaScript. The player has to guess a randomly generated number between 1 and 100 within 10 attempts.

Features

Random number generation between 1 and 100.

User input field to enter guesses.

Feedback messages indicating if the guess is too high, too low, or correct.

Limited to 10 attempts; after which the game ends.

Reset button to start a new game.

Basic styling with CSS for an engaging UI.

Technologies Used

HTML for structuring the game interface.

CSS for styling and improving user experience.

JavaScript for game logic and interactivity.

How to Play

Enter a number between 1 and 100 in the input field.

Click the Submit button to check your guess.

A message will appear telling you if your guess is too high, too low, or correct.

You have a maximum of 10 attempts to guess the correct number.

If you guess correctly or use all attempts, the game ends.

Click Restart to play again.

Installation & Setup

Download or clone this repository.

Open the index.html file in a web browser.
